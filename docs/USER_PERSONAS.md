# User Personas

## Persona 1: The High-Performing Professional
A busy, data-oriented user who wants efficient training that fits tightly into a demanding schedule.

## Persona 2: The Ambitious Beginner
A new user who wants guidance, structure, and confidence without intimidation.

## Persona 3: The Recovery-Focused Athlete
A user who is balancing high performance with recovery, fatigue, and stress management.

## Persona 4: The Long-Term Builder
A user focused on sustained progression, mastery, and milestone achievements over years.

## Shared Needs
- Clear evaluation.
- Meaningful progression.
- Adaptive recommendations.
- Calm, premium feedback.
