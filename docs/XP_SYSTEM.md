# XP System

## XP Sources
- Workout completion
- Quality of execution
- Recovery consistency
- Mission mastery
- Challenge completion
- Streak preservation

## Formula
Base XP is derived from effort score, difficulty, and consistency. Bonuses are applied for pace adherence, recovery discipline, and performance exceeding baseline.

## XP Presentation
XP is displayed through a cinematic bar with pulses, energy shards, and mission-specific visual bursts.
