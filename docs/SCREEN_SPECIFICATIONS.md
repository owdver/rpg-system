# Screen Specifications

## Home Screen
The home screen is the primary command surface. It presents current mission state, recovery index, energy, objectives, performance summary, XP, level, rank, notifications, and AI recommendations in a polished holographic dashboard.

## Current Mission Screen
Shows the active mission, its difficulty, expected outcomes, relevant stats, and a visible progress state. It acts as a mission briefing window.

## Training Screen
Presents a live HUD with rep counter, timer, heart rate, calories, remaining sets, current exercise, XP gains, and combo status. It should feel like a tactical interface rather than a workout tracker.

## Recovery Screen
Surfaces sleep, fatigue, readiness, hydration, stress, and recommended recovery action. The system should present recovery as a strategic resource.

## Progress Screen
Shows stat growth, personal records, history, charts, achievements, and progression milestones. The experience should feel analytical and future-facing.

## Inventory Screen
Displays unlocked cosmetics, titles, effects, badges, and progression rewards. Each item should feel like a system artifact or capability enhancer.

## Skill Tree Screen
Presents branching skill progression with passive, recovery, strength, and movement paths. The visual language should feel alive and exploratory.

## Settings Screen
Controls profile, health integrations, notifications, privacy, and system preferences while preserving the premium immersive interface.
