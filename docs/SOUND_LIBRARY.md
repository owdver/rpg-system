# Sound Library

## Purpose
Provide subtle, high-quality audio cues that reinforce the system experience without cluttering it.

## Sound Assets
- panel.open
- panel.close
- crystal.ping
- energy.surge
- mission.success
- warning.alert
- level.up
- system.start
- button.click
- achievement.unlock
- recovery.warning
- recovery.success

## Properties
- Volume, pitch, duration, trigger, category, and priority.

## Usage Rules
- Keep sounds short and non-repetitive.
- Use lower volume for ambient and higher impact for milestone moments.
- Support silent mode and reduced motion via mute settings.
