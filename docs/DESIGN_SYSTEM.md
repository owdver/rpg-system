# Design System

## Visual Language
The interface should feel like a holographic operating system that has awakened around the user. It should combine glass surfaces, floating windows, animated borders, bloom, scanlines, particles, refraction, and neon energy effects in a way that feels premium and original.

## Design Principles
- Minimal but immersive.
- Dense with information but never cluttered.
- Every interaction should feel reactive and alive.
- Every transition should feel like a system event rather than a simple screen change.
- No standard Material cards, normal buttons, or conventional fitness UI patterns should be used.

## Surface System
- Floating holographic panels with soft depth and glow.
- Layered gradients with cinematic lighting.
- Refraction and glass morphism for panels and overlays.
- Animated scanline and digital noise textures.
- Dynamic particle fields and volumetric light effects.

## UI Treatment Guidelines
- Backgrounds should be alive and always subtly moving.
- Interactive surfaces should react with energy pulses, shimmer, and digital projection.
- Status and progress surfaces should feel like live diagnostics rather than static charts.
- Large data values should have clear, premium visual hierarchy and legibility.

## Interaction Language
Every interaction should produce visual, motion, sound, and haptic feedback. The system should feel like it is observing the user in real time.
