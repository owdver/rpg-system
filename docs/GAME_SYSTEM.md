# Game System

## Design Intent
The fitness experience is structured as a progression fantasy where effort becomes capability, and capability becomes authority.

## Core Loop
1. Receive mission.
2. Execute effort.
3. Analyze output.
4. Receive evaluation.
5. Unlock growth.

## Systems
- XP system
- Level system
- Stat system
- Quest system
- Achievement system
- Title system
- Skill tree
- Season system
- Recovery and fatigue model
- Boss challenges
