# Animation System

## Motion Principles
No transition should simply fade. Every motion should materialize, project, dissolve, scan, or pulse into existence.

## Animation Model
- Materialize: object emerges from a scan field.
- Project: UI surfaces extend from a central origin.
- Dissolve: states transition through energy fragments.
- Scan: content reveals through structured light sweeps.
- Pulse: state changes create energy bursts.

## Motion Tokens
- Duration: 180ms to 900ms depending on priority.
- Curves: ease-out, spring, and custom energy curves.
- Delays: used to create cadence and anticipation.
