# Haptic Library

## Purpose
Provide tactile confirmation that reinforces interactions and milestones.

## Patterns
- light.tap
- light.doubleTap
- pulse.short
- pulse.medium
- impact.light
- impact.heavy
- warning.longPulse

## Usage Rules
- Use haptics sparingly and only when they add clarity.
- Avoid excessive triggering during long sessions.
- Respect accessibility and device compatibility.
