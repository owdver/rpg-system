# Information Architecture

## Primary Navigation
- Home
- Mission Control
- Training
- Progress
- Inventory
- System

## Content Structure
- Dashboard: current state, mission, recovery, performance summary.
- Training: active workout, adaptive plan, history.
- Progress: stats, XP, titles, achievements, reports.
- Inventory: cosmetics, equipment, rewards.
- System: settings, privacy, integrations, diagnostics.

## Information Hierarchy
The system prioritizes state, intent, and next action over raw data. Each screen surfaces what matters most in the moment.
